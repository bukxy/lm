# 🏰 Lord Mobile Helper
👉 [Accéder au site ⚔️](https://lord-mobile.peron-nicolas.com)

Bienvenue sur **Lord Mobile Helper** 🎮  
Un site pensé pour **aider les nouveaux joueurs** et éviter de répéter les mêmes explications encore et encore 😅

Ici, tout est centralisé, clair et rapide à consulter 🚀

---

## ✨ Pourquoi ce site ?

- 📚 Centraliser les infos importantes du jeu
- 🧠 Aider à mieux comprendre les mécaniques
- ⏱️ Gagner du temps

---

## 📋 Fonctionnalités

### 🏳️ Boosts de territoire
Toutes les infos sur les boosts actifs et leur impact.

### 🐲 Familiers
Liste complète, compétences active/pass

### 🏗️ Constructions
Temps, prérequis et conseils pour optimiser ta progression.

### 🎉 Événements
Détails des événements, récompenses et astuces pour en tirer le max.

### 🧮 Calculatrice de vitesses
Un outil ultra pratique pour calculer tes temps réels en prenant en compte :

- ⚡ Accélérateurs
- 🔬 Recherches
- 🔮 Fusions
- 🏋️ Entraînements
- ❤️ Soins
- 🧱 Murs

---

## 🚀 Objectif du projet

Rendre **Lord Mobile** plus accessible aux débutants tout en restant utile aux joueurs plus avancés.

---

*(à adapter selon ton projet)*

- 🌐 HTML / CSS / JavaScript

## 🐳 Docker
[Documentation docker](https://docs.docker.com/manuals/)

### ▶️ Démarrage du projet
```bash
docker compose up -d
```

⏹️ Arrêter les conteneurs
```bash
docker compose down
```

🔄 Rebuild des images
```bash
docker compose up -d --build
```

📄 Voir les logs
```bash
docker compose logs -f
```
